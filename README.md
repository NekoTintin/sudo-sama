# Sudo-sama

## Description
Sudo-sama is a Discord bot based on the Gemma3:4b model (change modelfile for another one).

### Personality
Tsundere, arrogant, but ultimately helpful. She will always deny helping you, but the more she helps, the more she will deny it.

## Usage
Just start ```start.sh```, deps will be installed if needed, also don't forget to install python
